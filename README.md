# Profile Page

A responsive personal profile page built with HTML and CSS.

**Live demo:** https://munibamajid.github.io/profile-page/

## What it includes
- Navigation bar with links to each section
- About, Projects, Skills, and Contact sections
- Responsive layout using Flexbox

## What I learned
- Structuring a page with semantic HTML
- Layouts with Flexbox and wrapping
- CSS variables for a consistent color scheme
- Deploying a site with GitHub Pages

## Run it locally
1. Clone the repo
2. Open `index.html` in your browser (or use VS Code Live Server)
